# 돌려입기 시뮬레이션 👕👖

내가 가진 옷으로 상의·하의 조합을 만들어 보고, 마음에 드는 룩을 룩북에 저장하는 **Electron 데스크톱 앱**입니다.

옷 사진을 올리면 배경이 자동으로 지워지고, 그렇게 만든 옷 이미지를 자유롭게 조합해 "오늘 뭐 입지?"를 미리 맞춰볼 수 있어요.

- 옷 사진은 **방바닥에 펼쳐 찍은 사진**을 쓰면 가장 잘 나옵니다. (옷과 바닥 색깔이 비슷하면 배경이 잘 제거되지 않을 수 있어요)
- 배경 제거는 **앱 안에서 오프라인으로** 처리됩니다. (인터넷 연결 불필요)
- 지금은 **상의·하의**만 다룹니다. 아우터·신발·악세사리는 같은 구조로 얼마든지 확장할 수 있어요. ([더 만들어보기](#-더-만들어보기) 참고)

## 🚀 실행하기

두 가지 방법이 있어요. **그냥 써보고 싶다면 1번**, 코드를 직접 돌려보거나 고치고 싶다면 2번입니다.

### 방법 1. 완성된 앱 받아서 쓰기 (비개발자 추천)

[**Releases**](https://github.com/haejiJang/outfit-simulation/releases) 페이지에서 내 컴퓨터에 맞는 파일을 받으세요.

#### 🍎 맥 (Apple Silicon)

1. `...-arm64-mac.zip` 을 다운로드하고 압축을 풉니다.
2. `Clothing Simulation.app` 을 `응용 프로그램` 폴더로 옮깁니다.
3. 처음 한 번은 **"앱이 손상되었기 때문에 열 수 없습니다"** 경고가 뜰 수 있어요. 이 앱은 애플 유료 인증서로 서명하지 않아서 생기는 현상인데, 아래 한 줄이면 해결됩니다. **터미널**(`응용 프로그램 > 유틸리티 > 터미널`)을 열고 입력 후 Enter:
   ```bash
   xattr -cr "/Applications/Clothing Simulation.app"
   ```
   > 💡 `xattr -cr ` 까지 입력하고 앱 파일을 터미널 창으로 **드래그**하면 경로가 자동으로 붙어요.
   > "인터넷에서 받았다"는 표식만 지우는 것이라 안전합니다. (최초 1회만 하면 됩니다)
4. 이제 앱을 더블클릭하면 실행됩니다 🎉

#### 🪟 윈도우

1. `...Setup...exe` 를 다운로드하고 실행합니다.
2. "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**을 누르세요. (서명 안 한 앱이라 뜨는 정상 안내입니다)
3. 설치가 끝나면 시작 메뉴/바탕화면에서 실행됩니다 🎉

### 방법 2. 소스 코드로 직접 실행 (개발자용)

1. **Node.js (18 이상)** 를 설치합니다 — https://nodejs.org 에서 `LTS` 버전.
2. 이 저장소를 받습니다. (초록색 `<> Code` → `Download ZIP`, 또는 `git clone`)
3. 터미널에서 받은 폴더로 이동한 뒤:
   ```bash
   npm install   # 처음 한 번만 (필요한 재료 내려받기, 1~3분)
   npm start     # 앱 실행
   ```

> ⚠️ **VS Code 안의 터미널에서는 `npm start` 가 안 됩니다.** VS Code가 설정해 둔 `ELECTRON_RUN_AS_NODE` 환경변수 때문에 Electron이 앱이 아니라 Node로 실행돼 버리거든요. **일반 터미널**(맥 터미널 / 윈도우 PowerShell)에서 실행하세요.

## 👗 이렇게 사용하세요

1. **옷 추가** — 홈에서 `옷장`으로 들어가 `+` 버튼을 누르고 옷 사진을 올리면, 배경이 자동으로 지워져 저장됩니다.
   - 📸 **방바닥에 펼쳐 찍은 사진**이 가장 잘 나와요. (옷과 바닥 색이 비슷하면 배경이 잘 안 지워질 수 있어요)
   - 아이폰 HEIC 사진도 그대로 올리면 알아서 변환합니다.
2. **조합하기** — 홈의 `매칭`에서 상의·하의를 하나씩 고르고, 드래그로 위치·크기를 맞춰 코디를 만듭니다.
3. **저장** — 마음에 들면 저장 버튼으로 룩북에 보관합니다. (놓은 모습 그대로 저장돼요)
4. **룩북** — 저장한 코디들을 넘겨 보며 "오늘 뭐 입지?"를 정합니다.

## ✨ 주요 기능

- **옷 추가** — 옷 사진을 올리면 배경을 자동으로 지워 투명 PNG로 저장합니다. (HEIC 사진도 자동 변환)
- **매칭** — 상의·하의를 하나씩 골라 `zone` 위에 올리고, 크기와 위치를 조절해 룩을 완성합니다.
- **룩 저장** — 배치한 그대로(위치·크기·앞뒤 순서까지) 룩북에 저장합니다.
- **룩북** — 저장한 룩을 하나씩 넘겨 보고, 필요 없는 룩은 삭제합니다.
- **옷장** — 가진 옷을 종류별로 모아 보고, 거기서 옷을 추가하거나 삭제합니다.

## 🖥 화면 구성

한 페이지 안에서 `.screen` 중 `active`가 붙은 하나만 보여주는 방식입니다.

```
            ┌─ 매칭 ──(save)──▶ 룩 저장 ──(save)──▶ 매칭
  홈 ───────┼─ 옷장 ──────────▶ 옷 추가
            └─ 룩북
```

| 화면                             | 역할                                                        |
| -------------------------------- | ----------------------------------------------------------- |
| **홈** (`start-screen`)          | 매칭 · 옷장 · 룩북으로 가는 입구                            |
| **매칭** (`matching-screen`)     | 상의·하의를 골라 `zone`에 배치하고 룩을 만든다              |
| **룩 저장** (`save-look-screen`) | 만든 룩을 확인하고 저장한다 (매칭의 save로만 진입)          |
| **룩북** (`lookbook-screen`)     | 저장한 룩을 넘겨 보고 삭제한다                              |
| **옷장** (`wardrobe-screen`)     | 옷을 종류별로 보고, 옷 추가 화면으로 가는 유일한 입구       |
| **옷 추가** (`add-screen`)       | 사진을 올려 배경을 지우고 옷으로 저장한다 (옷장에서만 진입) |

> 화면별 상세 명세와 UI 규칙(공통 클래스, 버튼 동작 등)은 커밋 히스토리와 [style.css](style.css), [renderer.js](renderer.js)를 참고하세요.

## 🗂 데이터 구조

올린 옷 사진과 만든 코디는 **인터넷(서버)이 아니라 내 컴퓨터 안에만** 저장됩니다. (별도 DB 없음) 저장 위치는 실행 방식에 따라 다릅니다:

| 실행 방식                             | 옷 데이터(`wardrobe/`) 위치                                                                                    |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| **완성된 앱** (방법 1)                | 맥: `~/Library/Application Support/clothing-simulation/`<br>윈도우: `%APPDATA%\clothing-simulation\` |
| **소스 실행** (방법 2, `npm start`) | 프로젝트 폴더 안 `wardrobe/`                                                                                   |

- 앱을 꺼도 데이터는 그대로 남아 있어요.
- **백업**하려면 위 `wardrobe` 폴더를 통째로 복사해 두면 됩니다. 다른 컴퓨터로 옮길 때도 이 폴더만 가져가면 돼요.
- 이 폴더를 지우면 옷·코디가 모두 초기화됩니다.

폴더 안은 이런 구조예요:

```
wardrobe/
├── items/            배경이 지워진 옷 이미지들
│   ├── <id>.png
│   └── ...
└── data.json         옷·룩 메타데이터
```

`data.json`은 `items`(옷)와 `looks`(룩) 두 배열로 이루어집니다.

```jsonc
{
  "items": [
    {
      "id": "ca9caed3f9c53db6", // 랜덤 16자리 hex. wardrobe/items/<id>.png 파일과 짝을 이룬다
      "kind": "top", // "top"(상의) | "bottom"(하의)
    },
  ],
  "looks": [
    {
      "id": "c20adbccc5ea2c57",
      "top": {
        "itemId": "fd87b9c705377144", // items 중 어떤 옷인지
        "cx": 0.506, // zone 안에서의 중심 x (0~1 비율)
        "cy": 0.324, // zone 안에서의 중심 y (0~1 비율)
        "w": 0.741, // zone 너비 대비 옷 너비 (0~1 비율)
        "z": 38, // 앞뒤 겹침 순서 (z-index)
      },
      "bottom": {
        "itemId": "325531a6cea73615",
        "cx": 0.498,
        "cy": 0.74,
        "w": 0.541,
        "z": 37,
      },
    },
  ],
}
```

**포인트**

- 좌표·크기를 **비율(0~1)로** 저장하기 때문에, 저장할 때의 모습 그대로 룩북에서 다시 보여줄 수 있어요.
- 이미지는 `data.json`에 넣지 않고 `items/<id>.png` 파일로 따로 둡니다. `data.json`은 "어떤 옷을 어디에 놓았는지"만 가볍게 기록합니다.
- 옷을 지우면 `items` 배열과 PNG 파일이 함께 지워집니다. 그 옷이 들어간 룩은 룩북에서 자동으로 건너뜁니다.

> `wardrobe/`는 개인 옷 데이터라 `.gitignore`에 들어 있어 저장소에는 올라가지 않습니다.

## 📁 프로젝트 구조

```
clothing-simulation/
├── main.js          Electron 메인 프로세스. 창 생성 + 파일/데이터 처리(IPC 핸들러)
├── preload.js       contextBridge로 렌더러에 안전한 window.api 만 노출
├── renderer.js      화면 전환·옷 배치·드래그/리사이즈 등 모든 UI 로직
├── index.html       화면(.screen)들의 마크업
├── style.css        전체 스타일
├── assets/
│   ├── images/      arrow·home·plus·trash 등 아이콘
│   └── fonts/       커스텀 폰트
└── wardrobe/        (gitignore) 옷 이미지 + data.json
```

**데이터가 흐르는 길**

```
renderer.js  ──window.api.xxx()──▶  preload.js  ──ipcRenderer.invoke──▶  main.js
   (UI)                              (브릿지)                           (파일/배경제거)
```

렌더러는 파일 시스템에 직접 손대지 않습니다. 항상 `window.api`를 거쳐 메인 프로세스에 요청하고, 메인이 `wardrobe/`를 읽고 씁니다.

`window.api`로 쓸 수 있는 것들 ([preload.js](preload.js)):

| API                         | 하는 일                                     |
| --------------------------- | ------------------------------------------- |
| `removeBackground(dataUrl)` | 사진에서 배경 제거 (HEIC면 PNG로 먼저 변환) |
| `listItems()`               | 옷 목록 불러오기                            |
| `addItem(kind, dataUrl)`    | 옷 추가 (이미지 저장 + 메타데이터 기록)     |
| `deleteItem(id)`            | 옷 삭제 (파일 + 메타데이터)                 |
| `listLooks()`               | 저장한 룩 목록                              |
| `saveLook(look)`            | 룩 저장                                     |
| `deleteLook(id)`            | 룩 삭제                                     |

## 🌱 더 만들어보기

이 앱은 "딱 여기까지"가 아니라 **마음대로 늘려 쓰라고** 만든 작은 베이스예요.
구조가 단순해서(옷 = `kind` + 이미지, 룩 = 배치 정보) 기능을 붙이기 쉽습니다.
떠오르는 대로, 원하는 만큼 자유롭게 고쳐 쓰세요. 몇 가지 아이디어만 적어둘게요 👇

- **🍂 계절 옷장** — 옷에 `season`(봄/여름/가을/겨울) 속성을 더해서, 겨울엔 겨울 옷만·여름엔 여름 옷만 보이게. 옷장 탭에 계절 필터를 하나 얹으면 딱이에요.
- **🧥 종류 늘리기** — 지금은 상의·하의뿐이지만, `kind`에 아우터·신발·악세사리를 추가하면 룩 완성도를 확 올릴 수 있어요. `items`의 `kind`와 룩의 레이어만 늘리면 되는 구조라 확장이 어렵지 않아요.
- **🖼 룩북 갤러리** — 저장한 룩을 하나씩 넘겨 보는 대신, 썸네일 그리드로 한눈에 쫙 펼쳐 보기. 좋아하는 룩에 즐겨찾기를 달아도 좋고요.

이 밖에도 룩에 이름·날씨·메모 붙이기, 코디 추천, 통계(제일 많이 입은 옷) 등 떠오르는 건 뭐든 좋아요.
**정답은 없으니, 원하는 대로 수정해서 자기만의 옷장으로 만들어 쓰세요!** 😊
